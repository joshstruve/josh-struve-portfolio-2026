# jstruve.dev

**Senior Design Engineer Portfolio**

### Overview
This repository contains the source code for jstruve.dev, demonstrating a rigorous approach to front-end architecture, strict accessibility standards, and systemic UI engineering. The interface is designed to minimize cognitive load and prioritize high-speed scannability by entirely stripping away marketing terminology, visual noise, and heavy frameworks. It serves as a literal proof-of-concept for high-performance, strictly governed web development that explicitly bridges the gap between design theory and technical execution.

### Architectural Principles
*   **International Typographic Style:** The visual architecture is heavily rooted in Swiss design principles, prioritizing objective clarity, high-contrast hierarchical typography, and the complete elimination of subjective ornamentation.
*   **Mathematical Strictness & Restraint:** Every structural element, spatial relationship, and typographic scale adheres rigidly to a baseline multiple of `1rem` (16px), embracing a low-friction "Zero UI" philosophy that relies entirely on native browser APIs for feedback.
*   **Generative Canvas:** The hero section features a performant, dependency-free HTML5 `<canvas>` rendering an animated, mathematically driven diagonal tile pattern that serves as both the primary kinetic interaction and the site's 16x16 pixel favicon.

### Technical Execution
*   **DRY Component Architecture:** Employs a data-driven, vanilla JavaScript architecture to construct and inject repeating DOM nodes, keeping the core HTML structurally pristine and highly maintainable.
*   **Absolute Performance:** Engineered from the ground up to achieve perfect Google Lighthouse scores across Performance, Accessibility, Best Practices, and SEO.
*   **Zero-Error Milestone:** The codebase strictly maintains a validated state of zero console errors, zero build warnings, and zero accessibility flags.

### Stack
*   **Core Structure:** Native HTML5 DOM paired with Vanilla JavaScript (ES6 Modules) for highly performant, dependency-free component rendering.
*   **Styling System:** Custom CSS and CSS Variables providing absolute thematic control over a foundation of structural Bootstrap primitives.
*   **Graphics & Interaction:** HTML5 Canvas API driving programmatic pattern generation without relying on external animation or graphic libraries.
